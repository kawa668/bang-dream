# 若叶睦 Live2D 直播动捕

## 快速启动

双击 `start-live2d.bat`。首次运行会自动安装依赖并生成模型配置，之后直接启动直播应用。

## 启动

```powershell
npm install
npm run prepare:models
npm run dev
```

## 热键

- F1：便装
- F2：活动剧情装
- F3：夏季校服
- F4：冬季校服

输出窗口聚焦时也可以用 1-4 切换。

控制台和右键菜单都按“人物 / 动作”组织：人物下再按角色和模型分类折叠显示，动作单独折叠分类，默认不展开。

## 动作

- 应用每隔几秒随机播放模型自带动作，不需要摄像头或动捕。
- 已接入 338 若叶睦 4 套和 037 千早爱音 17 套；每套模型使用对应公共动作库，活动剧情装目录还额外带有本地动作文件。

## 指定动作

控制台的动作列表会按当前模型独立显示，只列出该模型可用的动作；切换服装后自动刷新。选择动作后点击“播放”，会立即播放指定动作；之后 8 秒内暂停随机动作。

## 拖动

输出窗口覆盖全屏但默认点击穿透，不会挡住其他程序。鼠标移到模型上会自动进入可拖动状态，按住即可拖到屏幕任意位置；鼠标移开后自动恢复点击穿透。

## OBS

1. 新建窗口捕获。
2. 选择“若叶睦 Live2D”输出窗口。
3. 确认背景透明。

## 抖音/B 站直播伴侣

1. 在 OBS 中把输出窗口加入场景。
2. 开启 OBS VirtualCam。
3. 直播伴侣的摄像头选择 OBS Virtual Camera。
