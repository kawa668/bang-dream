# Live2D 桌面宠物 UI 美化设计

日期：2026-09-09
状态：已确认方向，进入实施

## 背景

现有项目是基于 Electron 的 Live2D 桌面宠物/直播应用（若叶睦、千早爱音、丰川祥子）。当前 UI 有两块：输出窗口的模型右键菜单，以及独立的控制台窗口。现状是：

- 控制台（`src/renderer/control.html` + `control.ts`）：白底表单，布局朴素，窗口固定 `320×420`，要容纳聊天、语音、LLM 设置、人物/动作切换，明显拥挤。
- 右键菜单（`index.html` 的 `#context-menu`）：白底简单列表。

本次目标：在不动底层逻辑（窗口点穿透、拖动、IPC、随机动作）的前提下，美化这两块 UI，并把控制台窗口尺寸调到能舒适承载内容的可用大小。

## 设计方向

主题定为**明亮且克制**，以「睦」的角色配色为灵魂，避免模板化默认值。取色自模型贴图：

- 雾感薄荷绿（发色）—— 选中态、主强调。
- 深靛海军蓝（校服）—— 标题、信息层级。
- 柔粉腮红（肤色/发梢）—— 极小面积的强调点缀。

控制台是操作工具，不做营销页式卡片堆叠，不引入泛紫/泛蓝单色板；用深靛做结构层级、薄荷绿做交互态、粉色做点缀。

## 设计令牌

```css
--ink: #2b3446;            /* 深靛主文字 */
--ink-soft: #5b6678;       /* 次要文字 */
--bg: #faf9f5;             /* 暖白底 */
--surface: #ffffff;        /* 卡片/输入面 */
--surface-muted: #f1f3ee;  /* 分组底/悬停 */
--border: #e2e5dd;         /* 边框 */
--mint: #7ea27f;           /* 薄荷绿 主要强调 */
--mint-soft: #dbe7da;      /* 薄荷绿 弱底 */
--on-mint: #ffffff;
--blush: #d98a9d;          /* 腮红粉 点缀 */
--focus: #2f6feb;          /* 键盘焦点环 */
```

间距采用 4px 基准的紧凑刻度（8 / 12 / 16 / 20 / 24）。圆角小圆角（8px 卡片内件，12px 面板），阴影柔和。

字体使用系统栈：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`。标题用加粗同族，不引入网络字体，保证离线可用。

## 控制台布局

从单列堆叠改为**清晰分区的单列面板**：

1. **顶栏**：标题「控制台」+ 全局状态。
2. **聊天**：主容量区，用户消息右对齐（深靛底），宠物消息左对齐（白/薄荷边），带作者标签；输入行 + 发送/清空。
3. **语音**：一行内联控制（开关 + 音色下拉），下方状态文案。
4. **LLM 设置**：`<details>` 折叠抽屉，字段用可见 label，输入框统一样式，保存按钮主强调。
5. **人物**：按角色 → 模型分类分级折叠，当前模型高亮深靛底。
6. **动作**：按当前模型分组折叠，选中态用薄荷绿。
7. **底栏**：状态/提示文案。

窗口尺寸由 `320×420` 调整为约 `460×680`，并设置 `minWidth/minHeight`，防止过度缩小。

## 右键菜单

改为主题化弹出层：暖白面、圆角、柔和阴影、分组标题、悬停态、overflow 滚动。逻辑（点穿透、`hitTest`、定位、关闭）保持不变。

## 可访问性

- 正文对比度 ≥ 4.5:1；交互控件有可见 `:focus-visible` 焦点环。
- 可点击目标最小 44px（Web 目标 ≥ 24×24，这里统一取舒适值）。
- 折叠/展开只在用户触发时过渡，尊重 `prefers-reduced-motion`。
- 表单保留 `<label>` 关联；状态/聊天用 live region 语义。
- 纯颜色不承载唯一信息（选中态同时有底色与加粗）。

## 验证

- `npm run build` 通过，`npm test` 通过。
- 用无头浏览器注入 `window.api` 桩，对 `control.html` 在 100% 与窗口缩小时截图检查布局。
- 逐项走可访问性清单（对比度、焦点、目标尺寸、折叠交互）。
